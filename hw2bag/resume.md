# Отчёт: задача о рюкзаке (hw2bag)

## Постановка

Нужно максимизировать сумму ценностей предметов при суммарном весе не больше вместимости `W`.

## Без эвристик (DP + жадный)

**`BagSolver.java`** — решатель с двумя режимами:
- **Точная динамика по весу** (одномерный массив, сложность `O(n · W)`), если `n · W ≤ 50_000_000`.
- Иначе **жадный алгоритм**: сортировка по удельной ценности `value/weight`, затем жадное заполнение рюкзака.

Проверка на малом тесте: для `data/ks_4_0` точная DP даёт сумму **19** (оптимум для этого набора).
