# Отчёт: задача о рюкзаке (hw2bag)

## Постановка

Нужно максимизировать сумму ценностей предметов при суммарном весе не больше вместимости `W`.

## Без эвристик (DP + жадный)

**`BagSolver.java`** — решатель с двумя режимами:
- **Точная динамика по весу** (одномерный массив, сложность `O(n · W)`), если `n · W ≤ 50_000_000`.
- Иначе **жадный алгоритм**: сортировка по удельной ценности `value/weight`, затем жадное заполнение рюкзака.

Проверка на малом тесте: для `data/ks_4_0` точная DP даёт сумму **19** (оптимум для этого набора).

## Расширение окресности для локального поиска

Полный перебор 2<->1 по-прежнему только при n ≤ 380. Иначе используется ограниченная окрестность:
2 вынуть — 1 взять: среди POOL_WORST_TAKEN_21 = 140 самых «плохих» по плотности взятых перебираются все пары; свободный предмет j берётся только из POOL_BEST_FREE_21 = 400 лучших по плотности среди невзятых.
1 вынуть — 2 взять: POOL_WORST_TAKEN_12 = 100 худших взятых × пары из POOL_BEST_FREE_12 = 160 лучших свободных

Результат:

| Файл | Результат |
|------|-----------|
| `data/ks_30_0` | 99798 |
| `data/ks_50_0` | 142156 |
| `data/ks_200_0` | 100236 |
| `data/ks_400_0` | 3967088 |
| `data/ks_1000_0` | 109869 |
| `data/ks_10000_0` | 1099870 |

Видно, что на ks_400_0 результат улучшился.
