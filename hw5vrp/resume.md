# Отчёт: CVRP (hw5vrp)

## Постановка

`V` машин грузоподъёмности `c`, **склад** (точка 0) и клиенты на плоскости со спросом `d_i`. Каждая машина — тур со склада по своим клиентам и обратно, на маршруте сумма спросов ≤ `c`. Минимизируем сумму длин туров (евклидова метрика).

## Первая итерация (dp + greedy)

Моё любимое, динамика + жадник: если `V^K` невелико (`K = n-1` клиентов), полный перебор «клиент - машина» при проверке вместимости и **DP по маскам** для оптимального TSP со склада на каждой машине. Иначе — **жадно**: последовательные маршруты с nearest neighbor; если не укладываемся в `V` рейсов, запасной вариант **FFD** по машинам и NN внутри каждой.
