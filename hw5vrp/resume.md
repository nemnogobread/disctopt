# Отчёт: CVRP (hw5vrp)

## Постановка

`V` машин грузоподъёмности `c`, **склад** (точка 0) и клиенты на плоскости со спросом `d_i`. Каждая машина — тур со склада по своим клиентам и обратно, на маршруте сумма спросов ≤ `c`. Минимизируем сумму длин туров (евклидова метрика).

## Первая итерация (dp + greedy)

Если `V^K` невелико (`K = n-1` клиентов), полный перебор «клиент <-> машина» при проверке вместимости и **DP по битмаскам** для оптимального TSP со склада на каждой машине. Иначе — **жадно**: последовательные маршруты с nearest neighbor; если не укладываемся в `V` рейсов, запасной вариант **FFD** по машинам и NN внутри каждой.

## Вторая итерация (2-opt)

После NN на каждой машине — **2-opt** по порядку объезда (клиенты на машине не меняются).

## Третья итерация (ослабление жадности + polish + relocate)

Четыре варианта построения (sequential NN / cheapest insertion × FFD first-fit / best-fit), `min` по всем; на туре — multistart NN, 2-opt, or-opt-1; затем **relocate** и **swap** между машинами.
