# Отчёт: задача о раскраске графа (hw3coloring)

## Постановка

Нужно минимизировать число цветов в раскраске графа так, чтобы любые две соседние вершины имели разные цвета.

## Первая итерация (без эвристик)

**`ColoringSolver.java`**:
- **Точный DP по подмножествам** для относительно малых графов (`n <= 70`).
- Для больших графов — **простой жадный алгоритм**: вершины сортируются по убыванию степени, после чего каждой вершине назначается минимальный допустимый цвет.

Запуск на наборах из чекера:

| Файл | Результат |
|------|-----------|
| `data/gc_50_3` | 5 |
| `data/gc_70_7` | 6 |
| `data/gc_100_5` | 21 |
| `data/gc_250_9` | 97 |
| `data/gc_500_1` | 18 |
| `data/gc_1000_5` | 124 |

Для gc_50_3 и gc_70_7 динамика дала решение даже за небольшое время, а остальные случаи надо дорабатывать эвристиками.

## DSATUR эвристика

По сути это более осмысленный жадный алгоритм - красить сначала вершины с наибольшей насыщенностью, те с наибольшем количеством закрашенных соседей. 

| Файл | Результат |
|------|-----------|
| `data/gc_50_3` | 5 |
| `data/gc_70_7` | 6 |
| `data/gc_100_5` | 18 |
| `data/gc_250_9` | 93 |
| `data/gc_500_1` | 16 |
| `data/gc_1000_5` | 115 |

Видно, что результаты улучшились, но всё ещё нужно дорабатывать решение (второй порог не везде достигается). Попробуем к этому добавить локальный поиск, точнее его усиленную вариацию - цепи Кемпе.

## DSATUR + цепи Кемпе

За основу взят DSATUR, по нему строим первоночальную раскраску. После, несколькими раундами пытаемся ужать решение с помощью жадных проходов и перетасовок цепей Кемпе (замена цвета двух группы вершин не нарушая правильность раскраски)

| Файл | Результат |
|------|-----------|
| `data/gc_50_3` | 5 |
| `data/gc_70_7` | 6 |
| `data/gc_100_5` | 17 |
| `data/gc_250_9` | 84 |
| `data/gc_500_1` | 16 |
| `data/gc_1000_5` | 114 |

Результаты улучшились (кроме gc_500_1).

После этого я поигрался чуть с параметрами и убрал/ослабил ограничения методов (локальный поиск без жёсткого `maxRounds = 200`, расширенный проход по вершинам, и увеличенные число свапов Кемпе за раунд), так как запас по времени был всё ещё большим. Результаты:

| Файл | Результат |
|------|-----------|
| `data/gc_50_3` | 5 |
| `data/gc_70_7` | 6 |
| `data/gc_100_5` | 15 |
| `data/gc_250_9` | 75 |
| `data/gc_500_1` | 16 |
| `data/gc_1000_5` | 107 |

## Итого

| Тест | Результат | Порог 3 б. | Порог 5 б. | Балл |
|------|-----------|------------|------------|------|
| `gc_50_3` | 5 | 8 | 6 | **5** |
| `gc_70_7` | 6 | 20 | 17 | **5** |
| `gc_100_5` | 15 | 21 | 16 | **5** |
| `gc_250_9` | 75 | 95 | 78 | **5** |
| `gc_500_1` | 16 | 18 | 16 | **5** |
| `gc_1000_5` | 107 | 124 | 100 | **3** |

На **5 баллов** прошли пять тестов; на **3 балла** — только `gc_1000_5` (до порога на 5 не хватает 7 цветов). **Сумма: 28 баллов.**
